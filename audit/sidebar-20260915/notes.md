# QC 右侧栏局部审查（2026-09-15）

## 1. AI 缓存状态

- 健康状态：需修改。
- 截图证据：`01-ai-status-before.png`。
- 问题：未缓存状态默认展开，占用大量有效标注列表高度；刷新操作和长说明与页面顶部 Flow 登录提示重复。
- 修改：默认收起为单行状态；未缓存显示黄色状态点，展开后只保留“登录 Flow 后自动补齐”。

## 2. 有效标注卡片

- 健康状态：需修改。
- 截图证据：`02-annotation-cards-before.png`。
- 问题：时间信息作为独立右列抢占宽度，中文标签被压成竖排；帧区间、绝对秒数和持续时长信息重复。
- 修改：卡片改为纵向信息结构；名称和来源同一行，对象信息第二行，帧范围和时长第三行；绝对秒数只保留在悬停提示中。

## 3. 宽侧栏空白

- 健康状态：需修改。
- 截图证据：`03-card-whitespace-before.png`。
- 问题：在较宽侧栏中仍沿用窄栏纵向结构，内容集中于左侧，右侧形成大面积无效空白。
- 修改：侧栏宽度达到 440px 时自动切换两列卡片；标签与来源在左列，目标信息、帧范围和时长在右列。窄侧栏继续保持纵向结构。

## 4. 有效标注标题区

- 健康状态：需修改。
- 截图证据：`04-header-spacing-before.png`。
- 问题：标题字号、上下留白与按钮高度共同形成过高的区块头，压缩了标注列表的可用高度。
- 修改：标题区上下间距缩小，主标题降为 13px，辅助标题降为 8.5px；折叠操作和数量仍保持可识别。

## 证据限制

- 两张截图足以确认布局挤压和信息重复，但不能单独证明键盘操作、屏幕阅读器语义或 QC-2 实机分辨率下的最终效果。
- 本机自动测试覆盖结构、AI 分界操作、历史继承和保存接口；部署后仍需在 QC-2 实际窗口验收。
